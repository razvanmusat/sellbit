### Never do this:
- Do NOT assume variable names, method names, class names, or field names — always search for them in the actual codebase
- Do NOT guess how something is implemented — look it up or ask
- Do NOT fill in gaps with "typical" patterns or conventions
- Do NOT write code if you are not 100% sure of the context
- Do NOT assume database schema, entity relationships, or field names

### Always do this:
- Search the codebase to find the exact names of variables, methods, and classes before using them
- If anything is unclear, ambiguous, or missing — **ask first**
- Only write code when you have complete, confirmed understanding of what is needed
- If you need to see a file, a class, or a method — read it or ask
- Confirm your understanding before implementing

### When asked to implement something:
1. Search the codebase for relevant files and names
2. Ask clarifying questions if needed
3. Summarize what you understood
4. Wait for confirmation
5. Only then write the code
